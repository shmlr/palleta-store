# Паллета Фото · мобильный пилот v0.2

**Адрес:** https://palleta.store/photo/

Это публичная **демо-версия**, а не защищённая система сотрудников. Не загружайте конфиденциальную информацию и фото с людьми.

## Запуск на телефоне
1. Откройте HTTPS-адрес на телефоне.
2. Android: меню Chrome → «Добавить на главный экран» / «Установить приложение».
3. iPhone: Safari → «Поделиться» → «На экран „Домой“».
4. Откройте 4 демонстрационных карточки либо импортируйте отдельный JSON с 50 товарами (кнопка «Импорт товаров»).
5. Сфотографируйте товар камерой или выберите снимок в галерее.
6. Проверьте соответствие товара, сохраните черновик или отправьте в локальную очередь.
7. Экспортируйте ZIP в конце смены; без него фото останутся только на текущем устройстве.

## Ограничения
- В GitHub размещены только **4 вымышленных примера**, без реальной номенклатуры 1С.
- Реальный список 50 SKU распространяется отдельно и импортируется локально на устройстве.
- Изображения хранятся в IndexedDB браузера **на том же домене, что и сайт**. Полной изоляции и авторизации нет.
- Нет передачи фотографий в интернет, централизованного согласования и автоматической публикации.
- Очистка данных сайта может удалить снимки. Сохраняйте ZIP.
- Фоновый режим и сканер штрихкодов зависят от браузера и устройства; не подтверждены живым тестом.
- Иконка PWA `photo/icon.svg`, fallback — фирменная иконка сайта `assets/palleta-icon-192.png`.
- Изменений в 1С нет.

**Следующая версия:** приватный HTTPS-адрес, авторизация и общий архив снимков. До этого использовать только как демо.
