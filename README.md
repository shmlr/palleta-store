# palleta.store — покупательский сайт-витрина

Черновик первой версии. Отдельный от Palleta Menu и OAuth, без корзины, онлайн-оплаты, подключения к приватной 1С или остатков.

## Готово
- Главная, клубные преимущества, доставка, контакты: +7 988 204 00 01, режим 24/7
- Переход на https://shmlr.github.io/palleta-menu/start.html
- Адаптивная мобильная верстка
- Отсутствие вымышленных фото, цен, адресов; WhatsApp/Telegram по номеру +7 988 204 00 01

## Публикация
1. Settings → Pages → Deploy from a branch → main → /(root).
2. Проверить временный URL https://shmlr.github.io/palleta-store/.
3. До переключения palleta.store подтвердить контакты, условия клуба и доставки, проверить мобильную версию, затем согласовать выпуск.
4. ТОЛЬКО ПОСЛЕ одобрения: добавить CNAME с palleta.store, заменить парковочные A-записи @ в Cloudflare на GitHub Pages IP и www на CNAME; не затрагивать oauth.palleta.store, MX/TXT без анализа.

Никакие приватные выгрузки 1С и секреты OAuth сюда не загружать.


## Объединение покупательских сайтов (19.10.2026)

Согласована схема с двумя независимыми GitHub-репозиториями:
- \`shmlr/palleta-store\` содержит брендовый сайт \`palleta.store\`.
- \`shmlr/palleta-menu\` остаётся источником приложения, рецептов, датированных клубных цен, тестов и Gmail-интеграции.
- Покупательское меню будет опубликовано в \`palleta.store/menu/\` после тестов и ручного слияния выпускного PR. Старый адрес не выключаем до проверки.

### Как выпустить новую версию меню

1. Открыть \`palleta-store > Actions > Prepare Palleta Menu release (PR only) > Run workflow\`.
2. Ввести \`menu_ref: main\` или SHA проверенного коммита меню.
3. Workflow тестирует меню, затем копирует только публичные разрешённые файлы в \`/menu/\`, немного скругляет углы **оригинальных** favicon/PWA-иконок.
4. Workflow создаёт PR \`automation/menu-release\`. **Не сливать**, пока не проверены 3/7 дней, список покупок, сохранение, офлайн-режим, клубные цены, правильный номер и мобильный вид.
5. После одобрения PR вручную объединить его с \`main\`.
6. GitHub Pages магазина должен публиковать ветку \`main\`, папку \`/(root)\`. Если Pages всё ещё смотрит на \`design/palleta-brandbook-v1\`, переключить на \`main\` в настройках Pages.
7. Перед назначением домена \`palleta.store\` отдельно проверить \`oauth.palleta.store\`, SSL, DNS, реальные адреса и условия доставки. Не менять OAuth DNS/MX.

### Риски и ограничения

- Сохранённые на старом домене планы хранятся в localStorage и не переезжают автоматически между доменами.
- Service Worker и PWA-манифест в \`/menu/\` остаются в пределах соответствующей папки.
- Исторические цены и остатки нельзя объявлять live-данными.
- Автоматический импорт XLS остаётся только в репозитории меню; в публичный магазин не копируются исходные XLS, закупочные цены, остатки, токены и внутренние скрипты.
- Правильный общий номер **+7 988 204 00 01** (телефон, WhatsApp, Telegram, MAX). Для MAX нужен подтверждённый прямой URL, поэтому пока только поиск по номеру.
- Для создания PR из GitHub Actions в настройках репозитория может потребоваться разрешить \`Allow GitHub Actions to create and approve pull requests\`.
